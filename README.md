# Diary Entry Application

A Python command-line application for dated diary entries.

## Run

With Python 3 installed, run:

```sh
python main.py
```

Enter a diary filename, or press Enter to use `diary.txt`. The menu lets you add entries, view all entries, search by date (`YYYY-MM-DD`), switch diary files, and exit. Each entry is saved on a separate line in the selected text file.

## Files

- `main.py`: application menu and user input.
- `diary.py`: date validation, file storage, and searching.
